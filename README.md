# Bank Loan Portfolio Analysis & Risk Insights

A portfolio data-analysis project demonstrating **Python, SQL, MS Excel and Power BI** skills using a synthetic bank-loan dataset.

## Objective
Analyze loan applications to identify patterns in:
- approval rates
- loan exposure
- customer segments
- credit-score bands
- debt-to-income ratio
- default/risk indicators

## Tools
- Python
- Pandas
- NumPy
- Matplotlib
- SQL
- Microsoft Excel
- Power BI

## Dataset
`data/loan_data.csv` contains 2,500 synthetically generated loan records.

**This is NOT real customer or bank data.** The dataset is created solely for educational and portfolio purposes.

## Key Questions
1. What is the overall loan approval rate?
2. Which employment categories have higher approval rates?
3. How does credit score relate to approval and default patterns?
4. Which loan purposes have the highest exposure?
5. How do debt-to-income ratio and existing loans relate to risk?
6. Which regions have the highest approved loan value?
