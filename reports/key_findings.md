# Key Findings (Synthetic Dataset)

> **Important:** This project uses a synthetically generated dataset for learning and portfolio demonstration. It does not represent ICICI Bank or any real bank/customer data.

## Portfolio KPIs
- Total applications: **2,500**
- Approved applications: **1,222**
- Approval rate: **48.88%**
- Approved loan value: **₹851,941,000**
- Average approved loan: **₹697,169**
- Default rate among approved loans: **5.32%**

## Business observations
1. Approval rates vary across employment categories, suggesting that employment profile can be one useful segmentation variable.
2. Credit-score bands show a clear relationship between credit quality and approval/default patterns in the synthetic dataset.
3. Loan purpose and loan amount can be used to segment portfolio exposure and compare approval performance.
4. Debt-to-income ratio and existing-loan count can be monitored as potential risk indicators.
5. A dashboard can help a relationship/portfolio manager monitor application volume, approval conversion, exposure and risk indicators together.

## Recommended dashboard KPIs
- Total Applications
- Approval Rate
- Approved Loan Value
- Average Approved Loan
- Default Rate
- Applications by Loan Purpose
- Approval Rate by Credit Band
- Approval Rate by Employment Type
- Loan Value by Region
